# Kardashev Civilization Simulator

An experimental strategy and civilization simulation project.

## Concept

Explore how civilizations develop through energy
harnessing, technological progress and resource management.

## Planned Features

- Civilization progression
- Energy generation and consumption
- Renewable energy systems
- Technology advancement
- Resource management
- Interactive simulation interface

## Technologies

- JavaScript
- HTML
- CSS

## Project Status

Concept and prototype development.
